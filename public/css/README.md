# Zombix CSS — "Nightfall" design system (v2.0)

`public/css/modules/` is the source of truth. `public/css/app.css` is generated by `npm run build:css` (minified, one request) and must never be edited by hand. The game loads only `css/app.css`; `public/game.css` and `public/ui-v100.css` are tiny compatibility imports.

## Rules

- **Tokens only.** Colours, radii, fonts, shadows and spacing come from `base/tokens.css`. Never hard-code a skin colour: use `--accent`, `--accent-2`, `--accent-ink`, `--accent-soft`, `--accent-line`, `--accent-glow`. Skins (`data-skin` on `#app`) only swap the accent ramp; `data-corners="square"` shrinks the radius scale.
- **One module per feature**, no cross-module overrides, no `@z-order` markers. Load order is fixed in `scripts/build-css.js` (`LAYER_ORDER`): base → account → menu → cases → profile → quests → economy → features.
- **Avoid `!important`.** It is only acceptable to beat inline styles written by JavaScript.
- **URLs are relative to the bundle**: `url("../png/…")`, `url("../fonts/…")`.
- **Visibility contract:** overlay roots are hidden by default and shown with `.show` (`display:flex`), unless the JS toggles `style.display`/`hidden` itself. Keep `position:absolute; inset:0` inside `#app` so overlays stay within the 500px game frame and fullscreen root.
- **Reduced motion** is handled globally in `base/motion-fonts.css`; JS-driven animation must also check `prefers-reduced-motion`.

## Typography

- `--z-font-ui` / `--z-font-game`: Rubik (variable 300–900, bundled woff2, Cyrillic + Latin). All readable text: body 14px, small labels 11–12px uppercase with `letter-spacing:.06–.1em`, headings 800 weight uppercase.
- `--z-font-pixel`: Press Start 2P. Brand/logo, the loading text and occasional numeric accents only — never body copy, never below 9px.
- Scale: `--fs-2xs` 10, `--fs-xs` 11, `--fs-sm` 12, `--fs-md` 14, `--fs-lg` 16, `--fs-xl` 20, `--fs-2xl` 26, `--fs-3xl` 34. Minimum readable size is 10px.

## Surfaces

- App background: `--bg-0`/`--bg-1` with an accent radial glow. Surfaces step up `--surface-1` → `--surface-4`. Hairlines: `--line`, `--line-strong`.
- Panels/dialogs: `background:var(--panel-bg); border:var(--panel-border); border-radius:var(--r-xl); box-shadow:var(--shadow-2)`, plus a 3px accent gradient strip on top (`::before`). Backdrop: `var(--overlay-bg)` with `backdrop-filter:blur(6px)`. Entrance: `animation:z-pop-in .25s var(--ease-out)`.
- Cards inside panels: `background:var(--card-bg); border:1px solid var(--line); border-radius:var(--r-lg)`.
- Primary button: `background:var(--btn-primary-bg); color:var(--accent-ink); box-shadow:var(--shadow-press)`, 46–52px tall, 800 weight uppercase. Secondary: `var(--btn-secondary-bg)` + `1px solid var(--line)`. Danger uses `--bad`. Touch targets ≥ 40px.
- Segmented controls/tabs: track `background:var(--bg-1); border:1px solid var(--line); border-radius:var(--r-md); padding:4px`, active segment `background:var(--accent-soft); color:var(--accent); box-shadow: inset 0 0 0 1px var(--accent-line)`.
- Inputs: 46px, `background:var(--bg-1)`, `1px solid var(--line-strong)`, focus ring `0 0 0 3px var(--accent-soft)`.

## Rarity

`.tier-1` … `.tier-6` expose `--tier` (`--t1` grey, `--t2` green, `--t3` blue, `--t4` purple, `--t5` orange, `--t6` red). JS also passes the tier colour inline as `--reel-tier-color` / `--drop-tier`. Item wells: square, dark inset (`radial-gradient` of the tier colour at ~18% over `--surface-1`), 1px tier-tinted border, bottom 3px tier bar.

## Shared pieces (`base/components.css`)

Generic modal shell `#simple-game-modal` (`.simple-game-card`, `.simple-game-title`, `.simple-game-modal-body`, `.simple-game-close`), `.item-atlas`, `.artifact-sprite`, `.z-btn`/`.menu-btn`, CSS pixel icons, scrollbars.
